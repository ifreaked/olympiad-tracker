# Календарь олимпиад по физике

Публичный календарь олимпиад школьников по физике на 2026–2027 учебный год. В
календарь попадают только даты, которые указаны точно; для остальных олимпиад
сохранены название, уровень, классы и ссылка на официальный сайт в
[`data/physics_olympiads.json`](data/physics_olympiads.json).

## Подписка в Яндекс Календаре

1. Откройте [Яндекс Календарь](https://calendar.yandex.ru/).
2. В левой колонке нажмите **Добавить календарь** → **Подписаться по URL**.
3. Вставьте URL:
   `https://ifreaked.github.io/olympiad-tracker/olympiads.ics`
4. Нажмите **Подписаться** и выберите цвет/название календаря.

Это именно подписка, а не импорт: Яндекс будет периодически проверять URL и
подхватывать изменения автоматически. Если обновление не появилось сразу,
откройте настройки подписки и нажмите **Обновить** (либо подождите следующий
цикл обновления Яндекс Календаря). Для ручной проверки feed доступен по тому же
URL в браузере.

Все события — целодневные, часовой пояс календаря — `Europe/Moscow`. В
заголовке используется формат `Название олимпиады | статус/этап`. Описание
состоит из отдельных строк `Уровень`, `Классы`, `Сайт` и, если нужно, заметки.
В iCalendar переносы представлены RFC 5545-экранированием `\n`; физического
переноса внутри свойства нет.

## Обновление данных

Отредактируйте `data/physics_olympiads.json`, добавив или изменив объект в
`events`. Для одного дня используйте `date`, для периода — `start` и
`end` (последний день включается). Не добавляйте предположительные даты:
запись с пустым `events` не создаёт событие в календаре.
Обычное событие получает `SUMMARY` из `name` и `title` через ` | `. Для
особых заголовков (например, предметных событий ВСОШ) укажите в событии поле
`summary`, чтобы не добавлять разделитель повторно. Дополнительные строки
описания задаются массивом `description`, а URL добавляется только при наличии
проверенного поля `url`. Если у олимпиады пока нет точных дат, её профили и
другие справочные сведения можно сохранить в объекте олимпиады, оставив
`events: []`: календарное событие при этом не создаётся. Например, профили
олимпиады «Высшая проба» хранятся в source data отдельно от DANO и не создают
датированных событий до появления точного расписания.

Проверка и генерация локально:

```bash
python -m unittest discover -s tests -v
python scripts/generate_calendar.py
```

GitHub Actions запускает тесты и генератор при изменении исходника, а также
еженедельно. Получившийся `docs/olympiads.ics` публикуется GitHub Pages из
каталога `docs`; в настройках репозитория выберите **Settings → Pages →
Deploy from a branch → main / docs**.
